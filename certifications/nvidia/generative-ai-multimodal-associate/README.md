# NVIDIA-Certified Associate - Generative AI Multimodal (NCA-GENM)

## Exam Overview

Entry-level certification for developers contributing to multimodal generative AI (text, image and audio): model development, programming and quality assurance. NVIDIA's code for this exam is **NCA-GENM**; this guide called it "NCA-MMGA" until 2026-10-22.

**Exam code:** NCA-GENM  
**Duration:** 1 hour  
**Questions:** 50-60 multiple choice  
**Cost:** $125 USD  
**Level:** Associate  
**Validity:** 2 years from issuance; recertify by retaking the exam  
**Delivery:** Online, remotely proctored; needs a Certiverse account  
**Prerequisites:** A basic understanding of generative AI  
**Passing score:** Not published
