# NVIDIA-Certified Professional - OpenUSD Development (NCP-OUSD)

## Exam Overview

Validates building, maintaining and optimising 3D content pipelines with OpenUSD. NVIDIA's code for this exam is **NCP-OUSD**; this guide called it "NCP-USD" until 2026-10-22.

**Exam code:** NCP-OUSD  
**Duration:** 120 minutes  
**Questions:** 60-70  
**Cost:** $200 USD  
**Level:** Professional  
**Validity:** 2 years from issuance  
**Delivery:** Online, remotely proctored, English; needs a Certiverse account  
**Prerequisites:** 2-3 years with the OpenUSD framework and Python or C++, or completion of the study guide materials (recommended)  
**Passing score:** Not published
