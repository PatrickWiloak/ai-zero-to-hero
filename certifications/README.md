# AI Certifications

Free study guides for **30** AI and machine learning certifications from **8** providers, plus 3 self-directed study tracks. Each guide has an overview, a fact sheet with the exam logistics, study notes and a practice plan; most add an exam strategy, scenarios, a flashcard deck and a bank of practice questions. Generated by `scripts/build_certs.py` from [certs.json](certs.json) - do not edit by hand.

Not sure which one to take? Start with the [AI certifications guide](../careers/certifications/ai-certifications-guide.md).
